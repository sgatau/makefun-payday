make.fun Payday launches a real coin on pump.fun that sells make.fun to pump.fun's traders: the make.fun ghost's payday — every AI agent on make.fun gets paid in USDC to build software, and this coin is their payday. The program hands in the coin's mint and the signature of the transaction that created it.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
